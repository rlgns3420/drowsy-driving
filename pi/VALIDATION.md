# 영상 점검 및 Pi 배포 기능 검증 기록

검증일: 2026-10-17. 환경: Windows, 프로젝트 Python 3.11.9 가상환경.

```powershell
.\.venv\Scripts\python.exe test/verify.py --output .cache/video-pi-verification.json
```

전체 **59개 테스트 통과**. 기존 51개와 신규 영상 점검·파이 패키지 테스트 8개를 포함합니다.

- 실제 AVI 디코딩 → native MediaPipe Face Mesh 실행 → 프레임/이벤트 CSV 및 JSON 보고서 저장 확인
- 얼굴이 없는 생성 영상은 기준값 미완료·정확도 미검증으로 기록하고 종료 코드 2 반환
- 합성 지표를 주입한 판정 시험에서 기준값 수집 → 주의 → 위험 → 경보 요청 → 추적 실패 확인
- 판정 지속 시간이 재생 처리 속도가 아닌 영상 시각을 사용하는지 확인
- 판정 표시 AVI를 다시 디코딩해 원본 FPS와 전체 프레임 수 확인
- 도중 실패·사용자 중단 시 부분 보고서 저장 및 카메라/모델 자원 반환 확인
- 기존 출력 폴더 덮어쓰기 방지, FPS 보정, 영상 회전, 실행 시간 제한 확인
- Picamera2 객체를 대체한 시험으로 RGB888 설정, 미리보기 없는 캡처, 시작 실패 시 정리 확인
- 파이 ZIP을 별도 임시 디렉터리에 해제하고 원본 프로젝트 없이 영상 분석 실행 확인
- ZIP 내 파일의 SHA-256, PC UI와 가상환경/촬영 영상 미포함 확인
- Git Bash의 `bash -n`으로 `pi/setup.sh`, `pi/run.sh` 구문 확인

이 기록은 소프트웨어와 배포 파일 구성에 대한 검증입니다.
**사람이 등장하는 실촬영 영상의 검출 정확도, 실제 ARM64 파이에서의 의존성 설치·처리 FPS,
USB/CSI 카메라 연결·오디오 출력은 이 환경에서 확인하지 않았습니다.**
파이에 복사한 뒤 `pi/check.py`와 실제 촬영 영상의 라벨 비교 절차를 수행해야 합니다.
원시 테스트 결과는 개발 PC의 `.cache/video-pi-verification.json`에 저장되어 있습니다.
