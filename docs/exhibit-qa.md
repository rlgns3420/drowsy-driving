- M1: 카메라 오류 후 자원을 닫고 기본 4초 간격으로 자동 재연결. 판정 카드에 재연결 상태와 수동 버튼(R) 제공. 재연결 시 새 파이프라인으로 기준값 재수집. 대기 중 종료/수동 재시도 가능.
- 권장 1: 전시 모드에서만 얼굴 소실 기본 5초 후 복귀 시 기준값 재수집. 시간 및 활성화 여부는 display 설정으로 조정.
- 권장 2: 전시 모드 Esc 2초 내 두 번 눌러 종료.
- 권장 3: 영상 위에 시뮬레이션 (실제 카메라 아님) 배너.
- 권장 4: --exhibit 별칭 추가, OpenCV UI와 함께 사용 시 경고 로그.
- 권장 5: README에 시스템 볼륨 확인 안내.
- 미반영 항목 없음. PR 머지하지 않음.

## 검증

기존 57개와 신규 7개, 총 64개 테스트 통과. 신규 테스트는 카메라 열기 실패→읽기 실패→복구, 종료 및 수동 재시도로 재시도 대기 해제, 얼굴 소실 시간/모드/비활성화 경계, 수집 완료된 기준값 폐기, Esc 두 번 및 수동 복구 제어를 검증.

전체 스위트 실행도 시도했으나 MediaPipe NSOpenGLPixelFormat 생성 불가로 native graph/CLI/배포 통합 테스트 4개는 not run(environment_unavailable). 해당 4개를 제외한 실행 가능한 테스트가 위 64개다. 로그: .cache/qa-tests.log, .cache/qa-unit-tests.log.

실제 GUI 렌더링, Windows, USB 웹캠 분리·재연결: not run(environment_unavailable). mock 검증은 실제 장치 복구의 확인을 대체하지 않는다. 현장에서는 USB 분리 후 재연결하여 자동 영상 복구와 재수집을 확인해야 한다.
