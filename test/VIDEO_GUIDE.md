# 실제 촬영 영상으로 동작 점검

## 1. 영상 준비

차량을 안전하게 정차한 상태나 실내에서 촬영합니다. 얼굴·양쪽 눈·입이 보이도록 카메라를 고정합니다.
영상 시작에 **정면을 보고 눈을 뜨고 입을 닫은 정상 구간 35초 이상**을 넣습니다.
기준값은 유효 정상 자세 30초가 모여야 완성되므로 추적 누락이 있으면 더 길어야 합니다.
이어 정상, 자연스러운 눈 깜빡임, 1초 눈 감김, 5초 이상 눈 감김, 회복,
입 벌림, 고개 이탈, 얼굴이 가려지는 구간 등을 촬영해 비교합니다.
입 벌림 검출을 실제 하품이나 피로 판정과 동일하게 해석하지 않습니다.
이미 촬영된 영상에 정상 기준 구간이 없으면 분석이 계속 CALIBRATING일 수 있습니다.

입력은 OpenCV로 디코딩 가능한 MP4/AVI/MOV입니다. 시간은 **프레임 번호 / FPS**로 계산합니다.
처리 속도 때문에 눈 감김 지속 시간이 달라지지 않으며 프레임을 건너뛰지 않습니다.
가변 프레임률(VFR) 휴대폰 영상은 원래 타임스탬프와 오차가 생길 수 있으므로
먼저 고정 프레임률(CFR)로 변환한 영상을 사용하고, 라벨도 변환본의 시간에 맞춥니다.
`--fps`는 CFR 영상의 잘못된 FPS 메타데이터를 보정하는 옵션입니다.

## 2. 실행

프로젝트 루트에서 Python 의존성을 설치한 뒤 실행합니다.

```powershell
# 라벨 없이 전체 영상 분석, CSV/보고서 저장
.\.venv\Scripts\python.exe test/video.py --video "D:\videos\driver.mp4"

# 판정 화면을 보면서 실시간 속도로 재생, 판정 표시 영상도 저장
.\.venv\Scripts\python.exe test/video.py --video "D:\videos\driver.mp4" --preview --realtime --save-video

# 파이와 같은 설정으로 분석
.\.venv\Scripts\python.exe test/video.py --video "D:\videos\driver.mp4" --config config.pi.json

# 디코더가 자동 적용한 방향에 추가로 시계 방향 90도 회전
.\.venv\Scripts\python.exe test/video.py --video "D:\videos\driver.mp4" --rotation 90
```

Windows에서는 영상 파일을 `test/run-video.cmd` 위로 끌어놓으면
재생·분석·판정 표시 영상 저장이 함께 실행됩니다. 기존 한국어 대시보드의 **영상 열기**는 재생 확인용이고,
분석 자료를 남길 때는 `video.py` 또는 이 실행 파일을 사용합니다.
영상 점검은 무음으로 진행하며 경보 요청 여부는 별도로 기록합니다.

## 3. 결과 확인

기본 경로는 `results/video-날짜-시간/`입니다. `--output .\results\experiment-01`처럼
지정할 수도 있습니다. 이전 결과를 덮어쓰지 않도록 출력 폴더는 새 이름을 사용해야 합니다.

| 파일 | 확인할 내용 |
| --- | --- |
| `frames.csv` | 매 프레임 시간, 상태, 얼굴 추적, EAR/MAR, 고개 각도, 지속 시간, 경보 요청 |
| `events.csv` | 상태와 경보 요청이 바뀐 영상 시각, 판정 이유 |
| `report.json` | 개인 기준값 완료 시각, 첫 경고·위험·경보 시각, 추적 비율, 처리 FPS, 설정 |
| `annotated.avi` | `--save-video` 사용 시 생성되는 판정 표시 영상. 원본 오디오는 포함하지 않음 |

CSV는 Excel에서 열 수 있는 UTF-8 BOM 형식입니다. `TRACKING_LOST`는 추적 실패이며 정상으로 취급하지 않습니다.
`CALIBRATING` 중 `tracking_valid=1`은 얼굴 지표가 있다는 뜻이고 아직 졸음 판정은 아닙니다.
`alarm_requested=1`은 위험 근거가 충분히 지속되어 경보 조건에 도달했다는 뜻입니다.
판정 표시 영상은 원본 FPS로 저장되며 분석을 중단하면 완료된 프레임까지만 들어갑니다.
상태에 `interrupted`/`stopped`가 있으면 전체 영상 분석이 끝나지 않은 결과입니다.

기본 눈 감김은 개인 기준값 아래로 양쪽 눈 지표가 내려가고 약 0.8초 후 주의,
2초 후 위험, 위험 근거가 추가 2초 지속되면 경보 요청입니다.
지표 평활화와 프레임 간격 때문에 경계 시각에 차이가 있습니다.
정상 복귀에는 1초의 회복 유지 시간이 적용됩니다.
얼굴 추적이 끊어지면 지속 시간 근거와 경보 요청이 해제됩니다.

`processing_fps`는 실행 옵션에 따라 화면 표시·재생 대기를 포함합니다.
성능을 비교할 때는 `--preview --realtime --save-video` 없이 측정하세요.
라벨 없는 결과는 동작 점검 자료이며 검출 정확도를 뜻하지 않습니다.

종료 코드: 0=전체 분석 및 기준값 수집 완료, 1=입력/실행 오류,
2=분석 중단·기준값 미완료 또는 양쪽 평가 클래스 부족.

## 4. 사람이 지정한 정답 구간과 비교

`test/labels.example.csv`를 복사해 실제 영상 시각에 맞게 수정합니다.
`normal`, `drowsy`, `exclude`를 사용합니다. 기준값 수집 구간은 `exclude`입니다.

```powershell
.\.venv\Scripts\python.exe test/video.py --video "D:\videos\driver.mp4" --labels .\labels.csv --save-video
```

`report.json`의 `scoring`에 혼동행렬, 오탐률, 검출률, 평가 범위와 제외 사유가 저장됩니다.
정상·졸음 구간 모두 있어야 평가가 완료됩니다. 추적 실패로 제외된 비율도 함께 확인합니다.
정확한 1초 단위 평가 규칙과 기존 평가 도구는 [README.md](README.md)의 실영상 평가 절차를 따릅니다.
조명·안경·거리·다른 사람을 포함한 여러 영상에서 확인하고, 설정 조정용 영상과 최종 평가 영상을 분리하세요.
