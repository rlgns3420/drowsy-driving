# 로컬 검증 결과

검증일: 2026-10-05 (한국 시간). Windows, Python 3.11.9, OpenCV 4.10.0, MediaPipe 0.10.18 환경에서 확인했습니다.

| 검사 | 결과 | 확인 범위 |
| --- | --- | --- |
| 자동 테스트 | 51개 통과 | EAR/MAR, 고개 각도, 개인 기준값, 눈 감김·입 벌림·고개 이탈과 복합 판정, 짧은 깜빡임·한쪽 눈 감김 처리, 15/30 FPS 시간 기준, 추적 실패, 무음 화면 판정, 영상 평가, 자원 종료 |
| 실제 UI 창 | 통과 | 한국어 정상·주의·위험·추적 실패 표시, 경보음 끄기, 감지 시작·중지, 기준값 재수집, 카메라 오류 후 다시 시작 가능 |
| 실제 Face Mesh 모델 | 통과 | 한글 프로젝트 경로에서 모델 로드 및 검은 시험 영상의 실제 디코딩·추론·결과 저장. 얼굴 없는 영상에서 정확도 수치를 만들어내지 않음 |
| 카메라 0~3번 | 영상 수신 불가 | 실제 영상 수신 검사 실패. Windows 장치 조회에서도 카메라가 발견되지 않았으며, 카메라 0번은 샌드박스 밖에서도 재확인 |
| 실제 사람의 졸음 감지 정확도 | 미검증 | 사용할 수 있는 카메라 및 사람이 라벨링한 얼굴 영상이 없음 |
| 사고 예방 효과 / Pi 실기 성능 | 미검증 | 로컬 동작 검증으로 입증할 수 없음. 별도 실험과 Pi 장치에서의 검증 필요 |

UI 시뮬레이션과 합성 지표 테스트는 프로그램 동작 검증입니다. 얼굴 검출·눈 감김 분류의 실영상 정확도를 입증하지 않습니다. 눈 감김이나 입 벌림은 졸음의 간접 지표입니다.

실제 카메라 연결 후 [실행·평가 절차](README.md)를 따라 `verify.py --camera`와 `evaluate.py`를 실행하세요. 검출률·오탐률과 평가 범위·추적 실패 비율을 함께 보고해야 합니다.
