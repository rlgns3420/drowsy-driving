# 라즈베리 파이 이식 전 컴퓨터에서 점검하기

`test/`에는 직접 실행하는 점검 도구가 있고, `tests/`에는 자동 검사 코드가 있습니다. 카메라 감지와 영상 재생은 컴퓨터와 라즈베리 파이가 같은 기준값 수집·졸음 판정 코드를 사용합니다.

현재 환경에서 확인한 결과는 [검증 기록](VALIDATION.md)에 기록했습니다.

촬영 영상의 CSV·판정 표시 영상·보고서 저장은 [실영상 점검 안내](VIDEO_GUIDE.md),
파이용 파일 분리와 설치·실행은 [라즈베리 파이 설치 안내](../pi/README.md)를 참고하세요.

## 실행

프로젝트 최상위 폴더에서 실행합니다. 파이썬 3.11 환경과 `requirements.txt`에 적힌 필요한 패키지를 먼저 설치하세요.

```powershell
.\.venv\Scripts\python.exe test/local.py
```

윈도에서는 `test/run-local.cmd`를 더블클릭해도 됩니다. 기존 `main.py`도 윈도에서 한국어 화면을 엽니다. 라즈베리 파이·리눅스의 기본 화면은 OpenCV 창이며, `main.py --ui opencv`로 직접 선택할 수 있습니다.

1. USB 웹캠 또는 노트북 내장 카메라를 연결합니다.
2. **카메라 찾기**로 0~3번에서 실제 영상 수신이 되는 장치를 확인합니다. 다른 장치는 카메라 번호를 직접 입력합니다.
3. **웹캠 시작**을 누르고 정면을 봅니다. 눈을 뜨고 입을 닫은 정상 자세가 약 30초간 관측되어야 판정이 시작됩니다. 얼굴 누락과 비정상 자세에서는 수집이 일시중지됩니다.
4. 화면에 정상·주의·졸음 위험, 눈 감김/입 벌림/자세 이탈 시간과 눈 열림 비율(EAR)·입 벌림 비율(MAR)·고개 각도가 표시됩니다. 얼굴 추적 실패는 별도로 표시합니다.
5. **기준값 다시 수집** 또는 `C`로 재설정하고, **중지** 후 카메라를 변경할 수 있습니다. `Esc`는 종료합니다.

경보음은 기본으로 꺼져 있습니다. 체크박스로 켤 수 있으며, 소리를 꺼도 화면 판정은 계속 표시됩니다. 위험 상태 표시는 경보음 대기 시간보다 먼저 나타납니다. 녹화와 영상 업로드는 하지 않습니다.

```powershell
# 다른 일반 카메라를 바로 실행
.\.venv\Scripts\python.exe test/local.py --camera 1 --start

# 윈도 장치 드라이버 자동 선택이 실패할 때
.\.venv\Scripts\python.exe test/local.py --camera 0 --backend msmf --start

# 카메라 없이 화면과 판정 흐름 확인
.\.venv\Scripts\python.exe test/local.py --demo

# 촬영해 둔 영상을 실제 얼굴 특징점 추적으로 분석하며 재생
.\.venv\Scripts\python.exe test/local.py --video .\driver.mp4
```

시뮬레이션은 합성 지표를 입력합니다. 기준값 수집 시간을 2초로 줄이고 정상→눈 감김→회복→입 벌림→고개 이탈→추적 실패를 반복합니다. 항상 시뮬레이션 표시가 나타나고 소리는 재생하지 않습니다. 실제 카메라 모드의 30초 설정과 판정 기준은 바뀌지 않습니다.

카메라를 못 열면 USB 연결, 윈도 설정의 카메라·데스크톱 앱 권한, 다른 앱의 카메라 점유를 확인합니다. `auto`는 윈도에서 DirectShow→MSMF→기본 드라이버 순서로 **영상 수신까지** 확인합니다. 이 컴퓨터용 화면의 카메라 입력은 UVC 웹캠용입니다. 라즈베리 파이 CSI 카메라는 `pi/run.py --source csi`로 연결합니다.

## 자동 검증

```powershell
# 판정·기준값·카메라 대체 연결·영상 처리·자원 정리 검사
.\.venv\Scripts\python.exe test/verify.py

# 실제 카메라 0~3번에서 각 45프레임 수신 및 얼굴 특징점 처리 검사
.\.venv\Scripts\python.exe test/verify.py --camera

# 실제 화면의 상태 표시, 무음, 시작/중지, 재설정, 오류 복구 검사 후 자동 종료
.\.venv\Scripts\python.exe test/local.py --ui-smoke
```

검사 결과는 `.cache/verification.json`에 저장됩니다. 화면 검증 이미지는 `.cache/ui/`에 저장되며 합성 화면만 포함합니다. `--ui-smoke`의 화면 캡처 저장에는 개발 환경에 설치된 Pillow가 필요합니다. 일반 화면은 추가 화면 구성 패키지 없이 파이썬의 Tkinter로 실행합니다.

`verify.py` 종료 코드: 0=소프트웨어 검사 통과(카메라 옵션 사용 시 영상 수신도 성공), 1=자동 테스트 실패, 2=소프트웨어 통과지만 사용 가능한 카메라 없음. 카메라 검사 성공은 졸음 감지 정확도 검증을 뜻하지 않습니다. 응답하지 않는 드라이버는 장치별 25초 후 검사 프로세스를 종료합니다.

## 실영상으로 정확도 평가

정지된 환경에서 정면 정상 자세 35초 이상을 포함한 영상을 준비하고, 사람이 확인한 구간을 CSV로 작성합니다. 조명·거리·안경 조건과 서로 다른 사람을 포함해야 합니다. 촬영 동작만으로 실제 피로 여부를 확정할 수 없으므로 눈 감김 동작 검출 실험과 실제 졸음 실험의 정답을 구분합니다.

`labels.example.csv`는 형식 예시입니다. 시작·종료 초를 **실제 영상 내용에 맞게** 바꾸고 다른 파일명으로 저장하세요.

```csv
start,end,label
0,35,exclude
35,45,normal
45,52,drowsy
52,58,exclude
58,68,normal
```

`exclude`는 기준값 수집 등 평가에서 제외할 구간입니다. `normal`에는 짧은 눈 깜빡임·좌우 확인 같은 평상시 행동도 넣어 오탐을 확인합니다. `drowsy` 구간의 판정 지연도 평가에 포함되며, 사후에 오탐·미탐을 숨기려고 제외 구간을 바꾸지 않습니다.

```powershell
.\.venv\Scripts\python.exe test/evaluate.py --video .\driver.mp4 --labels .\labels.csv
```

결과는 `.cache/evaluation/report.json`과 `frames.csv`에 저장됩니다. 영상은 복사·저장하지 않습니다. 기준값과 판정 시간은 처리 속도가 아닌 영상의 초당 프레임 수(FPS)를 기준으로 계산합니다.

- 완전히 라벨링된 1초 구간에서 관측 프레임 절반 이상이 추적 가능해야 평가합니다.
- 추적 가능 프레임의 과반수(동률 포함)가 주의 또는 위험이면 양성으로 봅니다.
- 오탐률은 `FP / (FP + TN)`, 검출률은 `TP / (TP + FN)`입니다.
- 기준값 미완료, 얼굴 추적 실패, 라벨 경계, 불완전한 마지막 초와 영상에 없는 라벨 구간은 제외 횟수·평가 범위로 보고합니다. 추적 불가를 정상으로 계산하지 않습니다.
- 정상·졸음 양쪽의 평가 구간이 없으면 종료 코드 2를 반환합니다. 해당 분모가 없는 지표는 `null`로 기록합니다.

라즈베리 파이로 옮기기 전에는 정상 구간 오탐률뿐 아니라 졸음 구간 검출률, 추적 실패 비율, 눈 감김 후 경고·위험 표시까지의 시간, 초당 처리 프레임 수를 함께 확인하세요. 목표값을 실험 전에 정하고, 조정에 사용하지 않은 다른 영상에서 재검증합니다. 프로그램 동작 검증으로 실제 사고 예방 효과를 입증할 수는 없습니다.
